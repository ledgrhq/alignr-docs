## 1. Choose your Microsoft access path

<Frame caption="The setup wizard: Microsoft partner access. This local demo has no shared Microsoft application configured.">
  <img src="/images/walkthroughs/setup-partner.png" alt="Alignr setup wizard showing four steps, partner access guidance, the default connection method and partner account selector." />
</Frame>

- **Left:** choose a setup step. You can return to unfinished steps.
- **Centre:** prepare partner access, then select the workspace's default connection method and account.
- **Top right:** **Finish later** returns to the app; it does not establish that setup is complete.

For a client outside Partner Center, use a Direct connection. Follow the [Microsoft setup walkthrough](/integrations/microsoft-setup) for prerequisites, permissions and verification, or [the wizard guide](/guides/setup-wizard) for all four steps.

## 3. Read the client's checks

<Frame caption="Northwind Dental is seeded demo data. These controls need evidence and have never run; the screen is not showing passing assessments.">
  <img src="/images/walkthroughs/client-checks.png" alt="A demo client's Checks tab showing automated and manual check choices, coverage information, filters and controls needing evidence." />
</Frame>

Start with the client name, then read the status, evidence and last-checked information together. Open a check to investigate it. **Needs evidence** is an instruction to investigate the evidence path, not a lower-severity pass.

Follow [Your first assessment](/journeys/first-assessment) to move from this screen to a result you can explain. Use [troubleshooting](/guides/troubleshooting) when collection or evaluation is incomplete.

## 4. Ask for help in context

<Frame caption="Ask Alignr is beside the app. The scope chips show All clients and Overview in this example.">
  <img src="/images/walkthroughs/ask-alignr.png" alt="Ask Alignr panel open beside Overview, with client and page scope chips, suggested prompts and a message composer." />
</Frame>

Check the scope chips before sending a question. Choose a suggestion or describe the result you need explained. A configuration proposal must be reviewed before applying; this screenshot shows the starting panel, not a generated answer or saved change.

[Use the AI assistant](/guides/ask-alignr) includes prompt examples and the supported draft operations.

## 5. Prepare the client discussion

<Frame caption="Open a client's More menu, then Review reports. Preparing a review creates a fixed snapshot.">
  <img src="/images/walkthroughs/client-reports.png" alt="Client reports screen with a report-name field and Prepare review action for a demo client." />
</Frame>

Inspect the client's evidence and outstanding work before preparing a report. Check the saved output before sharing it. Later assessments do not rewrite an earlier snapshot.

Continue with [Prepare a client report](/guides/client-reports) and [Run a client meeting](/journeys/client-meeting).
