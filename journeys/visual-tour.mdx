Use these annotated screens to recognise the app before you start. Captures use seeded demonstration data; they do not show live customer results or prove that a connection or assessment is complete. Follow the [five-step setup guide](/guides/setup-wizard) for the current Microsoft, PSA, RMM, teammates and standards workflow.

## 1. Choose your Microsoft access path

<Frame caption="Microsoft setup is the first of five optional steps. This local demonstration workspace has not connected an account; application-availability notices depend on the deployment.">
  <img src="/images/walkthroughs/setup-partner.png" alt="Five-step Alignr wizard on the Microsoft step, showing partner access guidance, the connection method selector and partner account choice." />
</Frame>

The setup wizard starts with Microsoft partner access. Prepare a dedicated partner account and use the configured Alignr Partner application. A custom app registration is needed only if you deliberately choose that route. Select the workspace's connection method and partner account, request administrator consent, then authorise the partner account separately. The consent return alone does not verify access. You can skip this step and return later. **Finish later** returns to the app; it does not establish that setup is complete.

For a client outside Partner Center, use a Direct connection. Follow the [Microsoft setup walkthrough](/integrations/microsoft-setup) for prerequisites, permissions and verification.

The PSA step offers ConnectWise Manage, HaloPSA and Autotask for client and service context. The separate RMM step offers Datto RMM and NinjaOne for device observations. Both can supply client records for **Clients → Import clients**, where you review each record and create or link the right Alignr client. Saving credentials, importing client records and collecting device evidence are separate checkpoints. Browse the [integration catalogue](/guides/integration-catalogue) for the broader choice of tools.

Next, preview eligible staff from your MSP's Microsoft directory if connected, or invite teammates manually. In Standards, choose one domain and follow **Answer questions → Connect your tools → Review your standard**. Connector choices start with the domain's relevant tools; **Browse tools** also offers other categories and **All tools**. Existing connections and standards can be reused or reviewed.

Unfinished answers are restored in the same browser for your account and workspace. Saving creates an active standard with selected-client scope and no clients assigned. Choose **Deploy to clients** to assign it, then run checks as a separate step. New blank/general standards, library copies and checklist imports start disabled and workspace-wide by default; existing standards retain their saved scope. See [Build or import a standard](/guides/build-or-import-standard).

## 3. Read the client's checks

<Frame caption="Northwind Dental is seeded demo data. These controls need evidence and have never run; the screen is not showing passing assessments.">
  <img src="/images/walkthroughs/client-checks.png" alt="A demo client's Checks tab showing automated and manual check choices, coverage information, filters and controls needing evidence." />
</Frame>

Start with the client name, then read the status, evidence and last-checked information together. Open a check to investigate it. **Needs evidence** is an instruction to investigate the evidence path, not a lower-severity pass.

Follow [Your first assessment](/journeys/first-assessment) to move from this screen to a result you can explain. Use [troubleshooting](/guides/troubleshooting) when collection or evaluation is incomplete.

## 4. Ask for help in context

<Frame caption="Ask Alignr is beside the app. The scope chips show All clients and Overview in this example.">
  <img src="/images/walkthroughs/ask-alignr.png" alt="Ask Alignr panel open beside Overview, with client and page scope chips, suggested prompts and a message composer." />

Check the scope chips before sending a question. Choose a suggestion or describe the result you need explained. A configuration proposal must be reviewed before applying; this screenshot shows the starting panel, not a generated answer or saved change.

[Use the AI assistant](/guides/ask-alignr) includes prompt examples and the supported draft operations.

## 5. Prepare the client discussion

<Frame caption="Open a client's More menu, then Review reports. Preparing a review creates a fixed snapshot.">

Inspect the client's evidence and outstanding work before preparing a report. Check the saved output before sharing it. Later assessments do not rewrite an earlier snapshot.
