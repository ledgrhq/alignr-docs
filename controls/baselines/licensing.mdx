## Automated controls

Expand a control to see the exact population, expectation and defaults. A pass requires usable evidence for the selected population. A known contrary observation can prove failure; missing observations or an empty population must not become a pass.

<Accordion title="Enabled accounts hold a licence">

**Source:** Alignr Baseline (seeded). **Severity:** medium. **Declared autonomy:** `document_only`.

**Population:** subjects with an observation of **Account enabled** (`account_enabled`) equal to `true`.

**Expectation:** **Licence or entitlement** (`has_licence`) has a non-null observed value.

**Thresholds:** no configurable parameter is declared for this control.

**Required observations:** `account_enabled`, `has_licence`.

**Interpretation:** This checks that an observed licence value exists, not that the licence is paid, appropriate, actively used or required for every account type. Review exceptions for service and other special-purpose identities.

**Investigate:** confirm the client and subject, inspect source and observation time, then compare the actual value with the effective expectation. Review a supported change separately from the assessment.

```json
{
  "match": {
    "predicate": "account_enabled",
    "object": true
  },
  "expect": [
    {
      "fact": "has_licence",
      "op": "exists"
    }
  ],
  "severity": "medium",
  "title": "Enabled account holds no licence",
  "evidence": [
    "account_enabled",
    "has_licence"
  ]
}
```

</Accordion>

<Accordion title="Licence renewal dates are on file">

**Source:** Alignr Baseline (seeded). **Severity:** low. **Declared autonomy:** `suggest_only`.

**Population:** subjects with an observation of **Purchased seats** (`licence_seats_purchased`).

**Expectation:** **Next licence renewal** (`licence_renewal_date`) has a non-null observed value.

**Thresholds:** no configurable parameter is declared for this control.

**Required observations:** `licence_renewal_date`, `licence_seats_purchased`.

**Interpretation:** This checks that a renewal value is present, not that the date is in the future or the commercial terms are suitable.

**Investigate:** confirm the client and subject, inspect source and observation time, then compare the actual value with the effective expectation. Review a supported change separately from the assessment.

```json
{
  "match": {
    "predicate": "licence_seats_purchased"
  },
  "expect": [
    {
      "fact": "licence_renewal_date",
      "op": "exists"
    }
  ],
  "severity": "low",
  "title": "Purchased licence has no renewal date on file",
  "evidence": [
    "licence_seats_purchased",
    "licence_renewal_date"
  ]
}
```

</Accordion>
