The seeded Alignr Baseline is a reference from the seed catalogue, not a promise that every production workspace contains it. Library templates are copied as disabled drafts. See [Choose a baseline](/controls/baselines/overview) before enabling anything.

## Automated controls

Expand a control to see the exact population, expectation and defaults. A pass requires usable evidence for the selected population. A known contrary observation can prove failure; missing observations or an empty population must not become a pass.

<Accordion title="MFA required for active accounts">

**Source:** Alignr Baseline (seeded). **Severity:** high. **Declared autonomy:** `document_only`.

**Population:** subjects with an observation of **Account enabled** (`account_enabled`) equal to `true`.

**Expectation:** **MFA registered** (`mfa_registered`) equals `true`.

**Thresholds:** no configurable parameter is declared for this control.

**Required observations:** `account_enabled`, `mfa_registered`.

**Interpretation:** This checks MFA registration, not effective enforcement at every sign-in. Review policy coverage, allowed methods and emergency exclusions separately.

**Investigate:** confirm the client and subject, inspect source and observation time, then compare the actual value with the effective expectation. Review a supported change separately from the assessment.

```json
{
  "match": {
    "predicate": "account_enabled",
    "object": true
  },
  "expect": [
    {
      "fact": "mfa_registered",
      "op": "eq",
      "value": true
    }
  ],
  "severity": "high",
  "title": "Active account has no MFA registered",
  "evidence": [
    "account_enabled",
    "mfa_registered"
  ]
}
```

</Accordion>

<Accordion title="Dormant accounts are disabled">

**Source:** Alignr Baseline (seeded). **Severity:** high. **Declared autonomy:** `change_ticket`.

**Population:** subjects with an observation of **Account enabled** (`account_enabled`).

**Additional filter:** **Last interactive sign-in** (`last_sign_in`) is more than this many days in the past: parameter `dormant_days`.

**Expectation:** **Account enabled** (`account_enabled`) equals `false`.

**Default parameters**

| Parameter | Default | Allowed range |
| --- | --- | --- |
| Dormant after (days) (`dormant_days`) | `90` | 1–365 |

**Required observations:** `account_enabled`, `last_sign_in`.

**Interpretation:** Review the selected account population and its business purpose before acting. An automated disabled-state expectation does not authorise disabling an account.

**Investigate:** confirm the client and subject, inspect source and observation time, then compare the actual value with the effective expectation. Review a supported change separately from the assessment.

```json
{
  "match": {
    "predicate": "account_enabled"
  },
  "where": [
    {
      "fact": "last_sign_in",
      "op": "older_than_days",
      "value": {
        "param": "dormant_days"
      }
    }
  ],
  "expect": [
    {
      "fact": "account_enabled",
      "op": "eq",
      "value": false
    }
  ],
  "severity": "high",
  "title": "Dormant account is still enabled",
  "evidence": [
    "account_enabled",
    "last_sign_in"
  ]
}
```

</Accordion>

<Accordion title="Conditional access is enforced tenant-wide">

**Source:** Alignr Baseline (seeded). **Severity:** medium. **Declared autonomy:** `suggest_only`.

**Population:** subjects with an observation of **Policy scope** (`ca_policy_scope`) equal to `"All users"`.

**Expectation:** **Policy state** (`ca_policy_state`) equals `"enabled"`.

**Thresholds:** no configurable parameter is declared for this control.

**Required observations:** `ca_policy_scope`, `ca_policy_state`.

**Interpretation:** The title is broader than the measured condition: an observed All users policy being enabled does not establish all policy interactions, exclusions or sign-in enforcement.

## Manual checks

These are human reviews, not automated evidence. The interval below is the template default; review ownership, evidence and suitability for the client.

<AccordionGroup>

<Accordion title="Review effective conditional access coverage">

**Source:** BIOS Identity Assurance. **Default review interval:** 90 days.

Verify the intended account population is covered by enabled policies, required grant controls and approved emergency exclusions. Review policy interactions and test sign-in enforcement. Registration or an enabled policy alone does not prove MFA enforcement.

**Record:** who performed the review, when it was performed, the evidence, the conclusion and any follow-up or approved exception. A due review is not evidence of a completed review.

</Accordion>

<Accordion title="Review break-glass account governance">

**Source:** BIOS Identity Assurance. **Default review interval:** 90 days.

Confirm named emergency accounts, exclusions, monitoring and last access test against the approved policy.

**Record:** who performed the review, when it was performed, the evidence, the conclusion and any follow-up or approved exception. A due review is not evidence of a completed review.

</Accordion>

<Accordion title="Review OAuth consent governance">

**Source:** BIOS Identity Assurance. **Default review interval:** 90 days.

Review consent policy, verified publishers, privileged grants and documented exceptions.

**Record:** who performed the review, when it was performed, the evidence, the conclusion and any follow-up or approved exception. A due review is not evidence of a completed review.

</Accordion>

</AccordionGroup>
